## Архитектура

В качестве основной архитектура был выбран шаблон MVP

> MVP (Model-View-Presenter) — шаблон проектирования, производный от MVC, который используется в основном для построения пользовательского интерфейса.
>
> - Модель предоставляет данные для пользовательского интерфейса.
> - Представление - реализует отображение данных (Модели) и маршрутизацию пользовательских команд или событий Presenterʼу.
> - Presenter - управляет Моделью и Представлением. Например извлекает данные из Модели и форматирует их для отображения в Представлении.

Данный шаблон был выбран ввиду того, что при таком подходе view и model не связаны напрямую, т.е. при необходимости миграции проекта, например, из браузера в какую-то другую платформу, можно оставить модель, аналогично при миграции на другую модель, можно оставить view.

Взаимодествие происходит следующим образом, в файле-точке входа происходит создание view и model, далее эти сущности передаются в presenter, в котором происходит связывание.
Например:

- В методе `presenter.init`
  - Происходит получение товаров с помощью `Product.getProducts`
  - В view происходит создание карточек `view.createProductCard` с этими данными

### Models

- [BasketModel](src/models/basket-model.ts)
  - `getItemsCount` - получение количества товаров в корзине
  - `getPrice` - получение общей стоимости товаров в корзине
  - `getItems` - получение товаров
  - `addItem` - добавление товара
  - `removeItem` - удаление товара
  - `clearAll` - очистка корзины
- [OrderModel](src/models/order-model.ts)
  - `address` - адрес доставки
  - `paymentMethod` - способ оплаты (или пустая строка, если не выбран)
  - `email` - электронная почта покупателя
  - `phone` - телефон покупателя
  - `validateDeliveryData` - проверка корректности данных доставки
  - `validateContacts` - проверка корректности контактных данных
  - `makeOrder` - оформление заказа
  - `clearAll` - очистка всех данных заказа
- [ProductModel](src/models/product-model.ts)
  - `fetchProducts` - запрос товаров
  - `getProducts` - получение товаров
  - `getProductById` - получение товара по id

### Api

Для удобства работы с запросами реализован класс [Api](src/components/base/api.ts), состоящий из:

- `constructor` - сам конструктор, принимающий api url и заголовки запроса, которые будут прокидываться во всех последуюзищ запросах
- `get` - обертка для GET-запросов, принимающая адрес ресурса
- `post` - обертка для POST-запросов, принимающая адрес ресурка и тело запроса
- `protected handleResponse` - приватный метод для более удобной обработки ответов
